# 同学传给你源码后，视觉识别不生效的常见原因

你和同学各自开发小程序，同学改好了「计算机视觉」功能并把源代码传给你，你在自己电脑上打开后实现不了视觉识别，通常有下面几类原因。

---

## 一、云开发环境不是同一套（最常见）

- 小程序里的**云开发**（云函数、云存储、数据库）是**跟着「小程序 AppID」走的**，不是跟着代码走的。
- 你同学在他电脑上：用的是**他的 AppID**，开通了云开发，环境 ID 可能是 `cloud1-9gmowq9c924cc435`（或别的），云函数也部署在**他的**云环境里。
- 你拿到代码后：
  - 若用的是**你自己的 AppID**（或测试号、别的号），那云开发环境是**另一套**，里面一开始是空的，没有云函数、没有数据库集合。
  - 若 `app.js` 里写死了 `env: 'cloud1-9gmowq9c924cc435'`，这个 ID 是你同学的云环境，**你的账号没有权限访问**，所以云函数调不通、存储/数据库也看不到。

**你要做的：**

1. 用**你自己的小程序**（或和同学约定用同一个 AppID）在微信开发者工具里打开项目。
2. 在开发者工具里点「云开发」→ 开通/进入**你自己的**云环境（会得到一个属于你的环境 ID）。
3. 在 `app.js` 里把 `wx.cloud.init({ env: '...' })` 里的 `env` 改成**你这个项目当前用的云环境 ID**（在云开发控制台里可以看到）。
4. 云函数要在你自己的环境里**重新部署**（见下一节）。

---

## 二、云函数没有在你自己的环境里部署

- 云函数只有在**某个云环境里上传并部署**之后，才会在那个环境里存在。
- 你拿到的只是**源代码**（例如 `cloudfunctions/chatImage/` 文件夹），不等于已经部署到你当前用的云环境。

**你要做的：**

1. 微信开发者工具左侧找到「云开发」→ 打开云开发控制台，确认当前使用的是**你自己的**云环境。
2. 在项目里找到云函数目录，例如 `cloudfunctions/chatImage`。
3. 右键 `chatImage` → 选择「**上传并部署：云端安装依赖**」（或「上传并部署」），等部署成功。
4. 部署完成后，再在小程序里试一次「拍照讲解」。

---

## 三、数据库集合或权限问题（若仍用「异步任务 + 轮询」）

- 若视觉识别用的是「云函数先返回任务 ID，结果写进数据库，小程序再轮询数据库」的方式，那么：
  - 数据库里必须有一个集合（例如 `image_recognize_tasks`），且云函数有权限写、小程序有权限读。
  - 你这边若是**新环境**，集合可能没建过，或权限是默认的「仅创建者可读写」，小程序端用 taskId 去查时可能**读不到**，就会一直拿不到识别结果，看起来像「识别不了」。

**可选做法：**

- **做法 A**：在云开发控制台 → 数据库 → 新建集合 `image_recognize_tasks`，权限设为「所有用户可读」（仅用于开发测试）或按文档配置「云函数可写、用户可读」。
- **做法 B（推荐）**：改用「同步」版云函数：云函数里直接等识别完成再返回 `{ content: '...' }`，不再写数据库、不再轮询。**当前项目已改为同步版**（`cloudfunctions/chatImage/index.js` 直接返回 `content`，小程序端不再轮询数据库），你拿到代码后只要部署云函数、配置自己的 API Key 即可，无需建数据库集合。

---

## 四、智谱 API Key 不是你的或已失效

- 云函数里调用了智谱等视觉 API，需要有效的 **API Key**。
- 若 Key 是**你同学填的**，可能出现：
  - 同学后来改了自己的 Key，你这份代码里的 Key 已失效；
  - 或 Key 有调用限制/额度，只允许同学自己的账号或 IP 用。

**你要做的：**

1. 自己去 [智谱开放平台](https://open.bigmodel.cn/) 注册并创建一个 API Key。
2. 在云函数里把 Key 换成你的（或放到云函数「环境变量」里，在云函数里读环境变量，不要写死在代码里提交到公开仓库）。
3. 重新上传并部署该云函数，再试视觉识别。

---

## 五、开关或配置不一致

- 代码里有开关，例如：`USE_CLOUD = true`、`USE_IMAGE_RECOGNITION = true`，以及云函数名 `IMAGE_CLOUD_FUNC = 'chatImage'`。
- 若你或同学有一方改过这些，或合并代码时被覆盖，可能导致：  
  - 没走云函数（例如 `USE_CLOUD` 为 false）；  
  - 没走图像识别（例如 `USE_IMAGE_RECOGNITION` 为 false）；  
  - 云函数名和实际部署的不一致。

**你要做的：**

- 打开 `pages/ai/ai.js`，确认：
  - `USE_CLOUD = true`（用云开发时）；
  - `USE_IMAGE_RECOGNITION = true`；
  - `IMAGE_CLOUD_FUNC = 'chatImage'` 与云函数目录名、部署的云函数名一致。

---

## 六、如何确认是哪里出问题

1. **看控制台**  
   - 微信开发者工具 → 控制台：是否有报错（例如「云函数调用失败」「database permission denied」等）。
2. **看云开发**  
   - 云开发 → 云函数 → 是否有 `chatImage`，且最近有调用记录；若没有调用记录，多半是没部署到当前环境或 env 不对。
3. **看网络**  
   - 云函数里若请求了外网（如智谱 API），需确认云环境允许「云函数访问外网」（一般默认允许）。

---

## 小结：你拿到同学代码后建议按这个顺序做

1. 确认用的是**自己的**小程序 AppID 和**自己的**云开发环境，并在 `app.js` 里填对 `env`。
2. 在项目里**右键云函数 `chatImage` → 上传并部署：云端安装依赖**。
3. 把云函数里的**智谱 API Key** 换成你自己申请的 Key（或配置到环境变量）。
4. 若当前用的是「异步 + 数据库轮询」且你这边一直拿不到结果，可改用项目里的**同步版云函数**（直接返回 `content`），避免数据库和权限问题。
5. 确认 `ai.js` 里 `USE_CLOUD`、`USE_IMAGE_RECOGNITION`、`IMAGE_CLOUD_FUNC` 与当前用法一致。

按以上步骤做完，视觉识别一般就能在你本地/你自己的账号下正常实现。
