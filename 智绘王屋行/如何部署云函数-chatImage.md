# 如何部署云函数 chatImage（一步步操作）

在**微信开发者工具**里按下面做，就能把「拍照讲解」用到的云函数部署到你自己的云环境。

---

## 第一步：确认已开通云开发

1. 用微信开发者工具打开你的小程序项目（智绘王屋行）。
2. 点击顶部菜单栏或左侧边栏的 **「云开发」** 按钮（图标像一朵云）。
3. 若第一次点会提示「开通云开发」：
   - 点 **开通**，用微信扫码，按提示创建环境（例如起名「智绘王屋行」）。
   - 创建后会得到一个 **环境 ID**（如 `cloud1-xxxxx`）。
4. 在 **app.js** 里确认 `wx.cloud.init({ env: '你的环境ID' })` 中的 **env** 和云开发控制台里显示的**当前环境 ID** 一致（在云开发控制台左上角可看到当前环境）。

---

## 第二步：找到云函数文件夹

1. 在微信开发者工具**左侧**是项目文件树。
2. 找到并展开 **「cloudfunctions」** 文件夹（和 `pages`、`app.js` 同级）。
3. 在它下面找到 **「chatImage」** 文件夹（里面应有 `index.js`、`package.json` 等）。

如果看不到 `cloudfunctions`：
- 检查项目根目录下是否真有 `cloudfunctions/chatImage` 这个文件夹；
- 若没有，可能是项目没同步完整，让同学再发一份带云函数目录的完整代码。

---

## 第三步：指定云函数所在云环境（重要）

云函数必须「归属」到某个云环境，上传时才会进对地方。

1. 在左侧文件树里，找到 **「cloudfunctions」** 这一行（不要点进子目录）。
2. **右键** 点击 **「cloudfunctions」** 文件夹。
3. 在菜单里选 **「当前环境」** 或 **「选择云开发环境」**。
4. 在弹窗里选择你**当前要用的那个云环境**（和 app.js 里 env 一致的那个），确定。

这样该目录下所有云函数（包括 chatImage）都会部署到这个环境。

---

## 第四步：上传并部署 chatImage

1. 在左侧文件树里，找到 **「chatImage」** 文件夹（在 cloudfunctions 下面）。
2. **右键** 点击 **「chatImage」**。
3. 在弹出菜单里选择：
   - **「上传并部署：云端安装依赖」**  
   （有的版本写的是「上传并部署」或「上传并部署：所有文件」，选带「云端安装依赖」的更好，会帮你在云端装好依赖再运行。）

4. 点击后：
   - 底部或右侧会出现「上传中」「部署中」之类的提示；
   - 等几十秒到一两分钟，出现 **「上传成功」** 或 **「部署成功」** 即可。

如果失败：
- 看控制台或云开发里的报错（例如「未选择环境」：回到第三步选对环境）；
- 若提示「没有权限」：确认当前登录的微信号是该小程序的开发者/管理员。

---

## 第五步：确认部署成功

1. 再点一次顶部的 **「云开发」**，打开云开发控制台。
2. 在左侧选 **「云函数」**。
3. 在列表里应能看到 **「chatImage」**，且**最近更新时间**是刚才部署的时间。

---

## 第六步：试「拍照讲解」

1. 在模拟器或真机上打开小程序的 **AI 页**（愚仔·智能助手）。
2. 点击 **「试试拍照讲解景区景点」**，选一张图或拍一张。
3. 等待几秒，若云函数和 API Key 都正常，愚仔会返回一段对图片的讲解；若仍失败，看控制台报错或参考《视觉识别不生效-排查说明.md》检查环境和 API Key。

---

## 小结（你要点的东西）

| 步骤 | 操作 |
|------|------|
| 1 | 打开项目 → 点「云开发」→ 确保已开通并选对环境 |
| 2 | 左侧找到 **cloudfunctions** → 其下找到 **chatImage** |
| 3 | **右键 cloudfunctions** → 「当前环境」→ 选你的云环境 |
| 4 | **右键 chatImage** → **「上传并部署：云端安装依赖」** |
| 5 | 等提示「上传/部署成功」→ 到云开发里确认有 chatImage |
| 6 | 在小程序里试「拍照讲解」 |

按这个顺序做，部署云函数这一步就完成了。

---

## 若报错「Invoking task timed out after 3 seconds」

说明云函数执行时间超过了默认的 3 秒（下载图片 + 调智谱 API 常会超过）。需要把云函数的**超时时间**调大：

1. 微信开发者工具 → 打开 **「云开发」**。
2. 左侧点 **「云函数」**，找到 **chatImage**，点进去。
3. 在 **「配置」** 或 **「函数配置」** 里找到 **「超时时间」**，改成 **20 秒**（或 60 秒），保存。
4. 若没有「配置」入口，可在腾讯云开发控制台（从云开发控制台里点「在腾讯云控制台打开」）→ 云函数 → chatImage → 编辑 → 超时时间改为 20 秒。

项目里已在 `cloudfunctions/chatImage/config.json` 中加了 `"timeout": 20`，**重新上传并部署**一次 chatImage 后，部分环境会按 20 秒超时生效；若仍为 3 秒，请按上面在控制台手动改为 20 秒。
